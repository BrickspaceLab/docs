# Favicon

Favicon settings in **Theme settings > Favicon** set the small icon shown in browser tabs, bookmarks, and some search and sharing surfaces.



## How to change theme favicon

{% stepper %}
{% step %}
### Upload an image

* Open **Theme settings > Favicon**.
* Under **Favicon image**, select or upload your icon.
{% endstep %}

{% step %}
### Save and verify

* Save theme settings.
* Open the storefront in a new tab and confirm the tab icon updates (try a hard refresh or private window).
{% endstep %}
{% endstepper %}



### Notes on favicons

* Shopify scales the favicon to about 32×32 px; a square source around 400×400 px stays sharp.
* Simple marks read better than detailed artwork at small sizes.



## Favicon settings

| Setting        | What it controls                                                                 |
| -------------- | -------------------------------------------------------------------------------- |
| Favicon image  | Image used as the site favicon. Recommended about 400×400 px square; shown near 32×32 px. |
