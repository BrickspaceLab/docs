# Social media

Social media settings in **Theme settings > Social media** store profile URLs the theme uses for social icons and links.



## How to change theme social media

{% stepper %}
{% step %}
### Open social settings

* Open **Theme settings > Social media**.
{% endstep %}

{% step %}
### Add URLs

* Paste the full URL for each network you use.
* Leave unused networks blank so those links stay empty where the theme hides them.
{% endstep %}

{% step %}
### Preview the storefront

* Check the footer, header, or any block that reads these settings.
{% endstep %}
{% endstepper %}



### Notes on social links

* Use complete URLs (including `https://`) so links work on all devices.
* You do not need to fill every field.



## Social media settings

| Setting        | What it controls                    |
| -------------- | ----------------------------------- |
| TikTok URL     | Link to your TikTok profile.        |
| Instagram URL  | Link to your Instagram profile.     |
| X.com (Twitter) URL | Link to your X (Twitter) profile. |
| Facebook URL   | Link to your Facebook page.         |
| Pinterest URL  | Link to your Pinterest profile.     |
| Snapchat URL   | Link to your Snapchat profile.      |
| Tumblr URL     | Link to your Tumblr blog.           |
| Discord URL    | Link to your Discord server or invite. |
| LinkedIn URL   | Link to your LinkedIn page.         |
| Twitch URL     | Link to your Twitch channel.        |
| YouTube URL    | Link to your YouTube channel.       |
| Vimeo URL      | Link to your Vimeo profile.         |
