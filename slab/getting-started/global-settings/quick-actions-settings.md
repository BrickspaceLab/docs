# Quick actions

Quick actions settings in **Theme settings > Quick actions** set which product templates open in quick buy and quick edit when those features are used.



## How to change theme quick actions

{% stepper %}
{% step %}
### Open quick actions

* Open **Theme settings > Quick actions**.
{% endstep %}

{% step %}
### Set template names

* Enter **Quick buy template** if quick buy should use something other than the default product template.
* Enter **Quick edit template** if quick edit should use something other than the default product template.
{% endstep %}

{% step %}
### Test overlays

* Trigger quick buy and quick edit from collection or product contexts and confirm the correct layout loads.
{% endstep %}
{% endstepper %}



### Notes on quick actions

* Leave a field blank to use the default product template for that action.
* Values should match the product template name or handle you created in the theme editor.



## Quick actions settings

| Setting               | What it controls                                                                 |
| --------------------- | -------------------------------------------------------------------------------- |
| Quick buy template    | Product template for the quick buy overlay. Blank uses the default template.   |
| Quick edit template   | Product template for the quick edit overlay. Blank uses the default template.    |
