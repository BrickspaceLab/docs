# Installing Slab

Choose how you want to install Slab:

* **[Install from ZIP](installing-from-zip.md)** — upload the theme in the Shopify admin. Best if you plan to customize only in the theme editor.
* **[Install from GitHub](installing-from-github.md)** — full source control and local development. Start by **forking** the theme repository on GitHub, then clone your fork.
