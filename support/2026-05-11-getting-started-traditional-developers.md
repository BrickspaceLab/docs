# Getting Started with a Brickspace Lab Theme (for Traditional Web Developers)

## Problem

New customers coming from traditional web development backgrounds (e.g. ASP.NET, C#, SQL Server) are unsure how Shopify and Liquid theming works, and may also encounter broken documentation links from welcome emails.

## Broken Links in Welcome Email

If links from the getting-started email return a 404 or error page, use the direct support page while the issue is resolved:

- **General support & docs:** [https://brickspacelab.com/pages/theme-support](https://brickspacelab.com/pages/theme-support)

## How Shopify Differs from Traditional Web Development

| Concept | Traditional (ASP.NET) | Shopify |
|---|---|---|
| Server-side language | C# | Liquid (simple template markup) |
| Database | SQL Server | Shopify's hosted data store |
| Frontend | HTML/CSS/JS | HTML/CSS/JS (same!) |
| Deployment | Your server | Shopify's infrastructure |

**Key points:**

- You do **not** connect your own database. Product data, orders, and customers all live inside Shopify.
- You edit the store through **Shopify Admin** — no FTP or file server access needed.
- Liquid is the templating language used in theme files. It's far simpler than C# — think of it as HTML with `{{ variables }}` and `{% logic %}` tags.
- Your existing HTML, CSS, and JavaScript skills transfer directly.

## How to Purchase the Paper Theme

1. Go to **Online Store → Themes** in your Shopify Admin.
2. Click **Visit Theme Store** and search for **Paper by Brickspace Lab**, or use the official Brickspace Lab link.
3. After purchase, the theme appears under **Themes** in your store.
4. Click **Customize** to open the visual editor, or **Edit code** to work directly in Liquid/CSS.
