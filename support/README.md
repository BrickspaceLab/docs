# Support Articles

This folder contains documentation auto-generated from resolved Intercom support conversations.

Articles are drafted by the Doc Sync agent and committed to the `gitbook-drafts` branch for human review before merging to `main`.

## Structure

Files are named using the pattern:
```
YYYY-MM-DD-<slug>.md
```

Each file includes YAML frontmatter with the source conversation ID, capture date, and original tags.
