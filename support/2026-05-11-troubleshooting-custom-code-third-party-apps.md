# Troubleshooting Theme Issues: Diagnosing Custom Code and Third-Party App Conflicts

## Overview

Many theme issues stem from custom code additions, Shopify AI-generated code, or third-party apps interfering with theme behaviour. Before escalating to support, work through the following checklist.

## Diagnostic Checklist

### 1. Custom Code or Shopify AI Code

- Have you added any custom Liquid, JavaScript, or CSS to the theme files?
- Have you used **Shopify's built-in code-generating AI** (available in some admin panels)?

AI-generated code can introduce conflicts with theme logic. Try removing or commenting out any custom additions and test again.

### 2. Third-Party Apps

- Are any apps injecting scripts or modifying your storefront (e.g. review apps, page builders, chat widgets)?
- Temporarily **disable all third-party apps** and check if the issue persists.
- Re-enable one at a time to identify the conflicting app.

### 3. Is This a New Issue or Was It Always Present?

- If the issue appeared suddenly, consider: did you recently update the theme, install an app, or make a code change?
- If it was always present: check whether the same issue appears on a **fresh, unmodified install** of the theme using the Brickspace Lab demo store.

### 4. Theme Version

- Check your current theme version in **Online Store → Themes**.
- Compare it to the latest release in the Shopify Theme Store or Brickspace Lab changelog.
- Updating to the latest version may resolve the issue.

## Requesting Support

If the issue persists after working through the checklist, the support team may need **collaborator access** to investigate directly.

To grant access:
1. In Shopify Admin, go to **Settings → Users and permissions → Collaborators**.
2. Copy your **Collaborator request code**.
3. Share your **store URL** and the request code with the support team.
